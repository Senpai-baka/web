# Kitsune Bot – landing

Página estática estilo anime. Sin build ni dependencias.

## Estructura
- `index.html` – la página completa (HTML + CSS)
- `vercel.json` – configuración opcional de Vercel
- `.gitignore`

## Deploy
1. Sube el repo a GitHub.
2. En vercel.com → Add New → Project → importa el repo.
3. Framework Preset: **Other**. Deja Build Command y Output Directory vacíos.
4. Deploy.
